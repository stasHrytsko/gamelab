# Prototype name

Перед началом скопируйте эту папку в `prototypes/<название-прототипа>/`.

- Исходники прототипа храните в корне его папки.
- PNG-превью храните рядом с исходниками.
- Уникальные графические объекты храните в `assets/`.
- Общие объекты подключайте из `../../assets/`, не создавая дубликаты.
- Используйте `../../design-tokens.json` или импортируйте `../../design-tokens.css`.
