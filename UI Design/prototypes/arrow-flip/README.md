# Arrow Flip — экраны

Спека — `specs/36-arrow-flip.md`.

- `game-screen.png` — скетч игрового экрана, 390×664: уровень 2 сразу после
  первого хода. Блок 0 (→, зелёный) уезжает вправо за край, по дороге задел
  блоки 2 и 3 — оба повернулись на 90° по часовой, уже сменили цвет на новое
  направление (↓ жёлтый, ↑ коралловый) и застигнуты чуть светлее обычного, на
  середине угасания свечения (§7.2 спеки).
- `mockup.html` — исходник скетча. Пересобрать PNG:
  `headless_shell --window-size=390,664 --force-device-scale-factor=2 --screenshot=game-screen.png mockup.html`.

Новые объекты собраны из токенов кита: блок — тайл «Обычный», цвет — прямое
отражение направления (решение автора 2026-09-27): `←` синий, `→` зелёный,
`↑` коралловый, `↓` жёлтый — «красного» в ките нет, чистый `--ui-danger`
зарезервирован за проигрышем. Отметка «повернулся этим ходом» — тот же тайл,
на миг светлее (`filter: brightness`), гаснущий обратно к обычному цвету за
700 мс, и плавный переход `--c` на цвет нового направления за то же время,
что и поворот стрелки. Новых цветов, радиусов и теней нет.

## Анимация хода

`animation-demo.html` — живое демо на правилах `applyMove` и уровнях
`GAME_LEVELS` (стрелки ‹ › переключают уровни, «Замедлить ×4» — синхрон
поворотов с проездом). Числа и правила анимации — `specs/36-arrow-flip.md` §7.2.
Файл самодостаточный: токены вписаны, Poppins — с Google Fonts.
