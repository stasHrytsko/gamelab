# Arrow Flip — экраны

Спека — `specs/36-arrow-flip.md`.

- `game-screen.png` — скетч игрового экрана, 390×664: уровень 2 сразу после
  первого хода. Блок 0 уезжает вправо за край, по дороге задел блоки 2 и 3 —
  они повернулись на 90° по часовой и застигнуты чуть светлее обычного, на
  середине угасания свечения (§7.2 спеки).
- `mockup.html` — исходник скетча. Пересобрать PNG:
  `headless_shell --window-size=390,664 --force-device-scale-factor=2 --screenshot=game-screen.png mockup.html`.

Новые объекты собраны из токенов кита: блок — тайл «Обычный» синего цвета с
белой стрелкой; отметка «повернулся этим ходом» — тот же тайл, на миг светлее
(`filter: brightness`), гаснущий обратно к обычному цвету за 700 мс. Новых
цветов, радиусов и теней нет.

## Анимация хода

`animation-demo.html` — живое демо на правилах `applyMove` и уровнях
`GAME_LEVELS` (стрелки ‹ › переключают уровни, «Замедлить ×4» — синхрон
поворотов с проездом). Числа и правила анимации — `specs/36-arrow-flip.md` §7.2.
Файл самодостаточный: токены вписаны, Poppins — с Google Fonts.
