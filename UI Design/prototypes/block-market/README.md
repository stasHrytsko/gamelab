# Block Market — мокап

Идея — `ideas/approved/41-block-market.md`.

- `mockup.html` → `mockup.png` — два экрана 390×844:
  1. игровой экран: три счётчика (фигуры, линии, монеты), поле 8×8, рука
     из трёх фигур (выбранная выделена, что дальше — не показывается), три покупки с ценами (поворот, зеркало, замена). Призрак
     текущей фигуры ложится на поле и подсвечивает две строки, которые
     закроются (+4 монеты);
  2. шторка «Заменить фигуру»: каталог с ценами, недоступные по кошельку
     приглушены, выбранная фигура выделена, внизу кнопка с ценой.

Референсы: `UI Design/*.png` (PuzzleKit) и скриншот блочной игры от автора
(взяты только композиция: счётчик сверху, поле по центру, лоток снизу; тёмно-
синяя палитра и скошенные плитки скриншота не переносились — они вне токенов).

Новые объекты собраны из токенов, новых цветов, радиусов и теней нет:

- **плитка** — скруглённый квадрат, градиент от брендового цвета, тёмная
  кромка снизу, блик сверху (как «Игровые фишки» кита);
- **призрак фигуры** — клетка с 30% цвета и рамкой 70% цвета, как выделенная
  клетка кита;
- **строка, которая закроется** — рамка `--ui-yellow`;
- **монета** — жёлтый круг с внутренним кольцом и бликом, оттенки — из
  `--ui-yellow` через `color-mix`;
- **цена** — пилюля с монетой, `--ui-yellow` 22% на белом;
- **кнопка покупки** — карточка кита с иконкой 40×40 и ценой; состояние
  «недоступно» — `--ui-surface-muted` и `--ui-disabled`;
- **иконки** «поворот», «зеркало», «замена», «пересдача» — контур 2 px,
  скругления, как иконки кита. Только для этого прототипа; если игра пойдёт
  дальше, переезжают в `UI Design/assets/icons/`.

Шрифт — Poppins из `UI Design/fonts/` через `design-tokens.css`.

## Главный экран

`assets/home-screen.png` — арт автора (941×1672, с нарисованной кнопкой).
`assets/home-art.webp` — он же без кнопки (обрезка сверху, 941×1262), для игры:
под ним настоящая кнопка «Играть», низ арта растворяется в его размытой копии.

## Верх экрана (решение автора 2026-09-29)

Три плашки, у каждой значение и подпись:
- фигуры: сколько уже показано из 20 и сколько осталось показать;
- линии: сколько собрано из цели и сколько ещё нужно;
- монеты: сколько в кошельке из 10.
