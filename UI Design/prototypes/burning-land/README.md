# Burning Land — экраны

Спека — `specs/11-burning-land.md`.

- `game-screen.png` — скетч игрового экрана 390×720 для §7.1: уровень 5
  (BL-5-28) после первого хода `L c6 d6 e6 c5`. Огонь сделал шаг, игрок
  тащит домино (карточка в трее пустая), призрак стоит на `b4 c4`. Точки —
  клетки следующего шага огня. Внизу ряд «Дальше» — фигуры следующего хода.
- `mockup.html` — исходник скетча. Пересобрать PNG:
  `headless_shell --window-size=390,720 --force-device-scale-factor=2 --screenshot=game-screen.png mockup.html`.

- `assets/home-screen.png` — арт автора для главного экрана, `assets/home-art.webp` —
  он же без нарисованной кнопки «Играть» (обрезан по 1340 px); в игре кнопка настоящая.

Новые объекты собраны из тайла кита «Обычный» и токенов:

| Объект | Цвет | Второй канал |
|---|---|---|
| Огонь (фронт) | `--ui-coral` | пламя |
| Пепел | `--ui-surface-muted` с 16% `--ui-text` — чуть темнее пустой клетки, без объёма (решение автора 2026-09-27) | плоская клетка, угольки |
| Стена | `--ui-blue` | кладка |
| Дом | `--ui-yellow` | домик |
| Превью шага огня | `--ui-coral`, полупрозрачная точка | точка |
| Призрак фигуры | `--ui-blue`, полупрозрачный | пунктир |

Новых цветов, радиусов и теней нет.
