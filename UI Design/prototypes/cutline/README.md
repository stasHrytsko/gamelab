# Cutline — кликабельный макет

Идея — `ideas/backlog/42-cutline.md` (v2). Спеки ещё нет: макет нужен, чтобы
потрогать резку пальцем до Gate 1.

- `mockup.html` — играбельный экран, два уровня. Открыть в браузере напрямую
  (токены и Poppins берутся из `../../design-tokens.css`).
  - **Уровень 1** — обучающий, цвет назван: «Сохрани 3 синих, разрезов 2».
  - **Уровень 2** — подобран солвером (динамика по дереву): синих 9, без лимита
    можно спасти 6, но за 3 разреза — только 1; коралловых 7, за 3 разреза
    спасается ровно 5. Ответ — коралловые; ловушка цвета и ловушка резки
    одновременно.
- `make-artifact.mjs` — собирает самодостаточный HTML (токены и шрифты внутри)
  для публикации артефактом: `node make-artifact.mjs <выход.html>`.
- `game-screen.png` — уровень 2 в стартовой позиции, 390×720.
- `press-preview.png` — палец на линии: то, что упадёт, бледнеет, на линии
  ножницы, внизу «Упадёт: −6 синих −2 коралловых».
- `lose.png` — поражение «Разрезы кончились», «Можно было 5», цвет открыт по
  тапу «Показать, какой цвет».
- `win.png` — победа коралловыми, 5 / 5.

## Как устроено

- Сеть — SVG. Узел: колонка, ряд, родитель, тип (крючок, развилка, круг).
  Линии только горизонтальные и вертикальные, как на референсе автора.
- Нажатие: касание линии подсвечивает падающую часть, отпускание на той же
  линии режет, увод пальца отменяет. Зона нажатия — 30 px в экранных пикселях
  (`vector-effect: non-scaling-stroke`), линия рисуется в 3 px.
- Падение — WAAPI на группе: короткий рывок в сторону ветки, потом вниз с
  поворотом, `fill: 'forwards'`, группа удаляется. Ввод заблокирован, пока
  ветка летит. `prefers-reduced-motion` сводит длительности к нулю.
- Конец уровня: остался один цвет → победа, если кругов не меньше цели; иначе
  поражение с кодом причины (`cuts`, `short`, `wrong`, `empty`,
  `unreachable`). Одна отмена разреза за уровень — кнопкой внизу или из
  попапа поражения.

## Вид

Только токены кита. Круги — тайлы кита (градиент от `--c`, блик, тень), цвет
дублируется значком: синий — круг, коралловый — треугольник, зелёный —
квадрат. Крючок и развилки — `--ui-text` и `--ui-text-muted`; линии —
`--ui-text-muted` с прозрачностью 0.55. Новых цветов, радиусов и теней нет.

Проверено в Chromium: оба уровня проходятся, синие на уровне 2 проигрывают,
отмена нажатия ничего не режет, на 360×560 и 430×932 нет прокрутки.
