# Раскоп — экраны

Спека — `specs/24-excavation.md`. Тема «Гробница» (тёмная,
`data-theme="tomb"`) — одобрена автором 2026-09-27, токены в
`UI Design/design-tokens.css` и `themes.tomb` в `design-tokens.json`.

- `game-screen.png` — скетч игрового экрана 390×664 для §7.1: уровень 5,
  раскладка seed 5035, открыты все гарантированно безопасные плиты, выход
  найден (левый край, второй ряд). Золото 23,
  первая звезда (18) есть, до второй (26) не хватает трёх, «Забрать 23»
  активна — момент главного решения.
- `tiles.png` — все состояния плиты: закрыта, вход, пусто, найденный выход,
  числа 1–5 с монетками, а в
  конце попытки — сработавшая ловушка, раскрытая ловушка и неоткрытая
  безопасная плита.
- `mockup.html`, `tiles.html` — исходники. Пересобрать PNG:
  `headless_shell --window-size=390,664 --force-device-scale-factor=2 --screenshot=game-screen.png mockup.html`,
  `headless_shell --window-size=390,430 --force-device-scale-factor=2 --screenshot=tiles.png tiles.html`.
- `hold-peek.png` — скриншот из собранного `apps/excavation` (не пересобирается
  headless_shell'ом из статического мокапа): удержание открытой плиты «2»
  подсвечивает трёх закрытых соседей и плашку «2 ловушки среди этих плит».

| Объект | Цвет | Второй канал |
|---|---|---|
| Закрытая плита | тайл `--ui-stone` | объём и трещины |
| Открытая плита | `--ui-surface-muted` | плоская |
| Число 1–5 | `--ui-clue-1..5`: синий, зелёный, коралловый, фиолетовый, розовый | сама цифра |
| Золото плиты | монетки `--ui-yellow` под цифрой, столько же штук | количество |
| Вход | `--ui-green` | круг со стрелкой вниз — «лаз, которым спустились» |
| Найденный выход | рамка и дверь `--ui-green`, цифра в углу | прямоугольная дверь на линии пола с ручкой — силуэт нарочно не похож на вход |
| Удержание плиты с числом | обводка `--ui-coral` на закрытых соседях | плашка «N ловушек среди этих плит» |
| Ловушка | тайл `--ui-coral` (сработала) или значок на плоской (раскрыта) | значок шипов |
| Звезда на шкале | `--ui-yellow` / `--ui-disabled` | заливка или рамка, число порога |

**Вход и выход переделаны 2026-09-27** (по просьбе автора «чтобы больше
отличались»): раньше оба были формой арки/двери с общим силуэтом, теперь вход
— окружность со стрелкой вниз, выход — прямоугольник с ручкой и линией пола.
Тот же файл `tools/brand.html` в `apps/excavation` использует те же два
символа — синхронизировано.

Черновик тёмного варианта (`mockup-dark.html`) после одобрения стал основным
`mockup.html`; светлого варианта больше нет.
