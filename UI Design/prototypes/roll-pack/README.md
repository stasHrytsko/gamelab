# Build & Pack — экраны

Спека — `specs/38-roll-pack.md`. Снимки собранного прототипа `apps/roll-pack`
(пересобрать: `npm run build && npx tsx tools/make-screens.ts`):

- `1-home.png` — главный: баннер фоном и карточкой.
- `assets/home-banner.png` — баннер от автора (исходник), `assets/home-banner.webp` — сжатая копия для игры.
- `2-levels.png` — уровни.
- `game-screen.png` — игровой экран, уровень 2, 390×664: две фигуры уложены,
  третья собирается, счётчик `4/6`.
- `game-small.png` — уровень 5 на 360×560: всё помещается без прокрутки.
- `3-help.png`, `4-lose.png`, `5-win.png` — «Как играть», проигрыш, победа.

История: `mockup-v2.*` (конструктор над полем — на телефоне поле обрезалось),
`mockup-v3.*` (раскладка, принятая в прототип).

Новые объекты собраны из токенов кита: клетка фигуры — тайл «Обычный» с белой
«таблеткой»; препятствие — клетка в косую штриховку цвета `--ui-disabled` с
тенью снизу. Цвет числа: 4 — зелёный, 5 — синий, 6 — коралловый, 7 —
фиолетовый. Новых цветов, радиусов и теней нет.
