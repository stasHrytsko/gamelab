# Брось и уложи — экраны

Снимки собранного прототипа `apps/roll-pack` для `specs/38-roll-pack.md`
(§7.1): главный, уровни, игровой экран посреди партии с выбранным кубиком,
«Как играть», проигрыш, победа.

- `game-screen.png` — игровой экран для §7.1 спеки.
- `1-home.png`, `2-levels.png`, `3-help.png`, `4-lose.png`, `5-win.png` — остальные экраны.
- Пересобрать: в `apps/roll-pack` — `npm run build && npx tsx tools/make-screens.ts`.

Новые объекты — планка и кубик — собраны из токенов кита: планка — тайл
«Обычный», растянутый на N клеток, с белой «таблеткой» на каждую клетку;
кубик — белая поверхность с точками цвета планки. Цвет планки по длине:
1 — фиолетовый, 2 — коралловый, 3 — жёлтый, 4 — зелёный, 5 — синий,
6 — коралловый. Длина читается по числу клеток и точек, цвет — только
подсказка. Новых цветов, радиусов и теней нет.
