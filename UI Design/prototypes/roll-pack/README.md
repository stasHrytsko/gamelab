# Build & Pack — экраны

Спека — `specs/38-roll-pack.md`.

- `mockup-v3.html` — актуальный мокап, играбельный уровень 1: поле сверху,
  внизу лоток с конструктором 4×4 и числами 4–7. Помещается без прокрутки от
  360×560.
- `mockup-v3.png` (390×664), `mockup-v3-small.png` (375×560) — снимки.
- `mockup-v2.*` — прошлая итерация: конструктор над полем, на телефоне поле
  обрезалось на 84–164 px.
- `game-screen.png`, `1-home.png` … `5-win.png` — первая версия игры
  (кубики и планки), история.

Новые объекты собраны из токенов кита: клетка фигуры — тайл «Обычный» с белой
«таблеткой»; препятствие — клетка в косую штриховку цвета `--ui-disabled` с
тенью снизу. Цвет числа: 4 — зелёный, 5 — синий, 6 — коралловый, 7 —
фиолетовый. Новых цветов, радиусов и теней нет.
