# Slide Out — экраны

Макеты семи экранов для `specs/02-two-moves-later.md`: главный, уровни,
игровой, «Как играть», победа, проигрыш, финал после уровня 5.

- `index.html` — исходник на `../../design-tokens.css` и Poppins.
- `preview.png` — все экраны на одном листе.
- `game-screen.png` — игровой экран для §7.1 спеки.
- `render.mjs` — пересобирает `preview.png` и `game-screen.png`.

Плитки — тайлы кита, у которых белая «таблетка» заменена знаком цвета: коралловый —
круг, синий — квадрат, жёлтый — треугольник. Новых цветов, радиусов и теней нет.
Раскладки игрового экрана и «Как играть» — уровни 4 и 1 из прототипа в play.

## Главный экран из авторского арта

Главный экран (§7.1 спеки) больше не собирается из тайлов кита — используется
авторский портретный арт «доска + небо + облака»:

- `assets/home-screen.png` — исходный арт, 941×1672, с нарисованной кнопкой
  «Играть» внизу.
- `assets/home-art.webp` — тот же арт, обрезанный до 941×1330 (без нарисованной
  кнопки — в игре кнопка настоящая, анимированная), 97 КБ; именно его
  импортирует `apps/slide-out/src/ui/screens.ts`.
- Фон экрана — небесный градиент, цвета взяты пипеткой с краёв самого арта
  (не новая палитра кита, см. `apps/slide-out/src/styles.css`, `.home`).

Ландшафтная версия арта (1672×941) — баннер игры для сайта-хаба:
`apps/slide-out/promo/site-banner.png` (оригинал) и
`site/public/games/slide-out-banner.jpg` (JPEG-копия, на неё уже смотрит
`site/src/games.ts`).
