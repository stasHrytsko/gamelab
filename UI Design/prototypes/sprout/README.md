# Sprout — экраны

Спека — `specs/09-sprout.md`.

- `game-screen.png` — скетч игрового экрана 390×664 для §7.1: уровень 3
  (SP-4-1992) после трёх шагов `f2 f3 e3`. На `e3` выпита вода, `+4` летит к
  счётчику «Ходы 5», соседние клетки кончика (`d3` и вода `e2`) обведены
  зелёным кольцом.
- `mockup.html` — исходник скетча. Пересобрать PNG:
  `headless_shell --window-size=390,664 --force-device-scale-factor=2 --screenshot=game-screen.png mockup.html`.
- `reference-sketch.png` — референс автора (7×7, шапка «Уровень · Ходы ·
  заново»). По решению автора 2026-09-26 поле стало 6×6, а шапка стандартной.
- `assets/home-screen.png` — арт автора для главного экрана. Кнопку «Play» в
  игре заменяет настоящая.
