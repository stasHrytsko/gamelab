# Такси-пятнашки — экраны

Макеты семи экранов для `specs/02-two-moves-later.md`: главный, уровни,
игровой, «Как играть», победа, проигрыш, финал после уровня 5.

- `index.html` — исходник на `../../design-tokens.css` и Poppins.
- `preview.png` — все экраны на одном листе.
- `render.mjs` — пересобирает `preview.png` и `specs/screens/02-two-moves-later.png`.

Такси — машинка сверху, `assets/taxi-car.svg`, одна на игру, макет и иконки.
Цвет кузова — `currentColor` из токенов; на белой табличке на крыше — знак цвета:
коралловый — круг, синий — квадрат, жёлтый — треугольник. Новых цветов, радиусов
и теней нет. `render.mjs` подставляет машинку в макет перед снимком.
Раскладки игрового экрана и «Как играть» — уровни 4 и 1 из прототипа в play.
