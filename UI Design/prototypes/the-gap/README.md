# The Gap — экраны

Спека — `specs/40-the-gap.md`.

- `game-screen.png` — скетч игрового экрана, 390×720: уровень TG-03 в
  стартовой позиции. Поле 4×3 с двумя стенами, четыре выхода с цифрами 1–4
  на рамке, под полем четыре колбы с теми же цифрами и вместимостью.
- `mockup.html` — исходник скетча. Пересобрать PNG:
  `headless_shell --window-size=390,720 --force-device-scale-factor=2 --screenshot=game-screen.png mockup.html`.

Новые объекты собраны из токенов кита. Квадрат — тайл «Обычный»: синий с
кругом и коралловый с треугольником, значок дублирует цвет для дальтоников.
Колба — белая карточка с `--ui-border`, слоты `--ui-surface-muted`. Бейдж
выхода и колбы — круг `--ui-text` с белой цифрой. Новых цветов, радиусов и
теней нет.
