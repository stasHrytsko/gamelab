# Tight Shelf — playable LAB prototype

Экспериментальный прототип для проверки ядра идеи `06-tight-shelf` до Gate 1.
Это не финальная игра и не папка `apps/`.

## Что проверяем

- каждый товар совместим ровно с двумя из четырёх полок;
- игрок видит текущий товар и три следующих;
- один ход = выбрать полку для текущего товара;
- три одинаковых товара на одной полке исчезают;
- уже размещённые товары не двигаются;
- неправильный выбор должен менять будущие варианты и может привести к тупику через несколько ходов.

В `playable.html` три фиксированные решаемые очереди. Рандома нет: если игрок
проиграл, причина — в цепочке его решений.

Открыть `playable.html` в браузере. Сборка и зависимости не нужны.

Идея остаётся `gate1: pending`: прототип нужен именно для проверки гипотезы
перед полноценной спекой и сборкой приложения.
