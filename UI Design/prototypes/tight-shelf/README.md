# Tight Shelf — экраны

Спека — `specs/06-tight-shelf.md`.

- `game-screen.html` → `game-screen.png` — скетч игрового экрана для §7.1,
  390×664: уровень 3, середина партии, текущая фигура — синий треугольник.
  Клетки, куда он не встаёт, приглушены.
- `game-screen-gray.png` — тот же экран в оттенках серого (`game-screen.html#gray`):
  проверка второго канала цвета. Без узора синий и коралловый сливаются,
  с узором — различимы.

Снимки собранного прототипа `apps/tight-shelf` (пересобрать:
`npm run build && npx tsx tools/make-screens.ts` в папке игры):

- `1-home.png` — главный: композиция из фигур вместо арта, живая кнопка «Играть».
- `2-levels.png` — уровни.
- `app-game.png` — игровой экран, уровень 3, семь фигур поставлено.
- `app-clear.png` — момент очистки линии на уровне 1: полоса, фигуры сжимаются.
- `app-small.png` — уровень 5 на 360×560: всё помещается без прокрутки.
- `3-help.png`, `4-lose.png`, `5-win.png` — «Как играть», проигрыш («Фигуре некуда встать»), победа.

Новые объекты собраны из токенов кита, новых цветов, радиусов и теней нет:

- **фигура** — inline SVG: силуэт — форма (скруглённый квадрат, круг,
  треугольник со скруглёнными углами), заливка — градиент от цвета, тёмная
  кромка снизу, блик сверху. Размеры подобраны на глаз под одинаковый вес:
  треугольник крупнее квадрата;
- **узор цвета** — белый полупрозрачный поверх цвета: синий гладкий,
  коралловый в косую полоску, жёлтый в точку;
- **клетка-правило цвета** — подкраска 26% цвета, рамка 60% цвета, тот же узор;
- **клетка-правило формы** — `--ui-surface-muted` с выдавленным контуром
  того же силуэта цвета `--ui-disabled`: фигура в него «вкладывается»;
- **джокер** — клетка `--ui-surface-muted` с точкой, как «Пустая» клетка кита.

фигурами 2026-09-28. `playable.html` — лабораторный прототип первой версии
идеи (товары и полки), от которой автор отказался 2026-09-28.
