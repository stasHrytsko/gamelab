# Arrow Flip — прототип

Спека — `specs/36-arrow-flip.md`, экраны и живое демо анимации —
`UI Design/prototypes/arrow-flip/`. Веб-игра под телефон: TypeScript + Vite,
без фреймворка, экран на HTML/CSS, стиль — токены и шрифт из `UI Design/`
(подключаются напрямую, не копией).

## Ссылки

| Ссылка | Что открывает |
|---|---|
| `https://<домен>/` | главный экран — эту ссылку и рассылать |
| `https://<домен>/#/levels` | экран уровней |
| `https://<домен>/#/level/3` | сразу уровень 3, если он уже открыт у игрока; иначе экран уровней |
| `https://<домен>/?unlock=all#/level/5` | любой уровень без прохождения предыдущих — для проверки, прогресс не трогает |

Маршруты в `#`, превью ссылки — `public/og.png`, иконка «На экран Домой» —
`manifest.webmanifest`; всё как у `apps/roll-pack`.

## Vercel

1. Vercel → Add New → Project → импортировать репозиторий `gamelab`.
2. **Root Directory: `apps/arrow-flip`.** Остальное Vercel возьмёт из
   `vercel.json` (Vite, `npm run build`, `dist`).
3. Опция «Include files outside the Root Directory» должна остаться
   включённой: сборка читает `../../UI Design`.

## Команды

```sh
npm install
npm run dev          # http://<ip-компьютера>:5173 — открыть с телефона в той же Wi-Fi
npm test             # движок: правила хода, повороты, победа/поражение; уровни: солвер,
                      # trap-free для обучающих, kill-критерий (жадная не решает 3–5)
npm run e2e          # главный → победа на уровне 1 → уровень 2 открыт; все пять уровней
                      # решением солвера; недопустимый тап; проигрыш и переигровка; «без прокрутки»
npx tsx tools/make-images.ts    # иконки и og.png из tools/brand.html
npx tsx tools/build-artifact.ts # один HTML-файл для превью на claude.ai
```

## Устройство

- `src/engine/flipEngine.ts` — правила §4–5 спеки: `planMove` — порт
  `applyMove` из `tools/arrow-flip-solver.mjs` (движение до препятствия или
  за край, повороты задетых на 90° по часовой, один раз за ход); `tap` —
  применяет ход к `GameState` и считает переход по §5 (победа → лимит →
  тупик). `solve`/`greedySolves`/`isTrapFree` — только для тестов и подбора
  уровней, в игре не используются: решаемость наперёд не проверяется
  (решение автора, §5 спеки).
- `src/levels/levels.ts` — пять уровней из `GAME_LEVELS` солвера: 1–2
  обучающие (`tutorial: true`, проиграть нельзя), 3–5 с обязательным
  setup-ходом (лимит без запаса, жадная стратегия не решает).
- `src/ui/game.ts` — игровой экран и анимация хода §7.2: квадрат задетого
  блока стоит на месте, крутится только стрелка, привязана к фактической
  позиции едущего блока на экране (не к таймеру); повёрнутый блок на миг
  светлеет и гаснет обратно за 700 мс.
- Лог §8 пишется только на устройство: `localStorage['arrow-flip:log']` — на
  каждом тапе блок, был ли готов к выходу, задел ли кого-то, время с
  предыдущего тапа.
