# Block Market

Идея — `ideas/backlog/41-block-market.md` (правила v2, симуляция, Gate 1).
Мокап — `UI Design/prototypes/block-market/mockup.png`.

Блочный пазл на поле 8×8. Игра сдаёт неудобные фигуры (тетромино и
пентомино), а удобство продаётся за монеты: поворот 90°, зеркало, замена на
выбранную фигуру, пересдача. Монеты приносят линии: 1, 4, 9 за 1, 2, 3 линии
за ход. Забег — до 12 уровней по 20 фигур, кошелёк до 10 монет.

**Не собрана по полному конвейеру:** спеки `specs/41-block-market.md` и Gate 1
ещё нет, арта автора для главного экрана нет, уровней «пять карточек» нет
(забег идёт подряд). Правила — из раздела «Правила v2» идеи; цифры лежат в
`src/engine/config.ts`.

## Проверка на игроках

Параметры адреса, любой комбинацией (`/?seed=5&level=8#/play`):

| параметр | что делает |
|---|---|
| `seed=N` | та же партия: камни, сдача, пересдачи. «Заново» повторяет её |
| `level=N` | забег стартует с N-го уровня (1–12) с 5 монетами |
| `goal=N` | одна цель по линиям на все уровни; `goal=0` — уровень проходится всегда |

Лог пишется только на устройство: в консоли браузера
`JSON.parse(localStorage['block-market:log'])`. События: `level_start`, `place`
(фигура, сколько было мест, линии, доход, кошелёк), `buy`, `buy_refused`
(`no_coins` или `no_change`), `help_open`, `level_win`, `level_fail`
(`goal_missed`), `run_win`.

Kill-критерий из идеи считается по логу: доля ходов с кошельком меньше 2 в
последней трети уровня (`turn` от 14) и доля трат по видам покупок.

## Команды

```sh
npm install                            # в корне репо
npm run dev                            # в папке игры
npm run check                          # typecheck + vitest + build + playwright
npx tsx tools/build-artifact.ts        # один HTML для артефакта
npx tsx tools/make-images.ts           # иконки и og.png из tools/brand.html
node ../../tools/block-market-sim.mjs --full 10000   # Monte Carlo экономики
```

## Устройство

- `src/engine/` — чистые функции правил. `catalog.ts` — 23 фигуры, цены,
  ориентации; `config.ts` — все числа; `engine.ts` — `startRun`, `place`,
  `rotateCurrent`, `mirrorCurrent`, `swapCurrent`, `rerollCurrent`,
  `nextLevel`. Каждое действие возвращает `{ state, event }` или `null`
  (недопустимо: ход и монеты не тратятся).
- `tests/engine.test.ts` — правила и **парность с симулятором**: константы и
  сдача фигур сравниваются с `tools/block-market-sim.mjs` на одном зерне.
- Сдача: каждым вторым ходом из нескольких кандидатов берётся самая
  неудобная, в остальных — случайная. Пересдача всегда случайная.
- Фигура, которой некуда встать, когда в кошельке меньше 2 монет, сгорает
  сама и тратит один из 20 ходов.
- Перетаскивание — pointer events; фигура висит выше пальца, на поле
  подсвечивается место, куда она ляжет, и линии, которые закроются.
- Экран помещается без прокрутки от 360×560 до 430×932; размер клетки —
  от свободного места (`ResizeObserver`), не меньше 18 px.
