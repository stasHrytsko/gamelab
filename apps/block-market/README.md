# Block Market

Идея — `ideas/approved/41-block-market.md`, спека — `specs/41-block-market.md`.
Мокап — `UI Design/prototypes/block-market/mockup.png`. Арт главного экрана —
`UI Design/prototypes/block-market/assets/`.

Блочный пазл на поле 8×8. На руках три неудобные фигуры (тетромино и
пентомино), любую можно взять сразу; что будет дальше, не показывается.
Удобство продаётся за монеты: поворот 90° и зеркало по 2, замена на выбранную
фигуру 5–8. Монеты приносят линии: 1, 4, 9 за 1, 2, 3 линии за ход. Пять
базовых уровней по 20 фигур; на каждом 5 монет на старте, кошелёк до 10.

Сверху три плашки: сколько фигур показано из 20 и сколько осталось; сколько
линий собрано и сколько ещё нужно; сколько монет.

**Собрана раньше спеки:** спеку записали по игре после сборки. Gate 1 принят автором
2026-09-29. Числа — в `src/engine/config.ts` (общие) и `src/levels/levels.ts`
(по уровням).

## Проверка на игроках

Параметры адреса: `/?goal=0#/level/3`.

| параметр | что делает |
|---|---|
| `unlock=all` | открывает все уровни |
| `seed=N` | своё зерно вместо зерна уровня (другая рука и камни) |
| `goal=N` | своя цель по линиям; `goal=0` — уровень проходится всегда |

Лог пишется только на устройство: в консоли браузера
`JSON.parse(localStorage['block-market:log'])`. События: `level_start`, `place`
(слот, фигура, сколько было мест, линии, доход, кошелёк, сколько сгорело),
`buy`, `buy_refused` (`no_coins` или `no_change`), `help_open`, `level_win`,
`level_fail` (`goal_missed`).

Kill-критерий из идеи считается по логу: доля ходов с кошельком меньше 2 в
последней трети уровня (`turn` от 14) и доля трат по видам покупок.

## Команды

```sh
npm install                            # в корне репо
npm run dev                            # в папке игры
npm run check                          # typecheck + vitest + build + playwright
npx tsx tools/build-artifact.ts        # один HTML для артефакта
npx tsx tools/make-images.ts           # иконки и og.png из tools/brand.html
node ../../tools/block-market-sim.mjs --full 10000   # Monte Carlo экономики (старая версия правил)
```

## Устройство

- `src/engine/` — чистые функции правил. `catalog.ts` — 23 фигуры, цены,
  ориентации; `config.ts` — общие числа; `engine.ts` — `startLevel`, `place`,
  `rotatePiece`, `mirrorPiece`, `swapPiece` (все с номером места на руке),
  `rescuable`. Каждое действие возвращает `{ state, event }` или `null`
  (недопустимо: ход и монеты не тратятся).
- `src/levels/levels.ts` — пять уровней: цель, камни, неудобство, зерно.
- `tests/engine.test.ts` — правила и парность с симулятором: общие константы
  и сдача фигур сравниваются с `tools/block-market-sim.mjs` на одном зерне.
- Сдача: каждым вторым ходом из нескольких кандидатов берётся самая
  неудобная, в остальных — случайная; двух одинаковых фигур на руке нет.
- Если ни одной фигуре некуда встать и никакая покупка не поможет (поворот,
  зеркало, замена с поворотом), левая фигура сгорает и тратит один из 20 ходов.
- Перетаскивание — pointer events; фигура висит выше пальца, на поле
  подсвечивается место, куда она ляжет, и линии, которые закроются.
- Экран помещается без прокрутки от 360×560 до 430×932; размер клетки —
  от свободного места (`ResizeObserver`), не меньше 18 px.
