# Build & Pack — прототип

Спека — `specs/38-build-pack.md`, экраны — `UI Design/prototypes/build-pack/`.
Веб-игра под телефон: TypeScript + Vite, без фреймворка, экран на HTML/CSS,
стиль — токены и шрифт из `UI Design/` (подключаются напрямую, не копией).

## Ссылки

| Ссылка | Что открывает |
|---|---|
| `https://<домен>/build-pack/` | главный экран — эту ссылку и рассылать |
| `https://<домен>/build-pack/#/levels` | экран уровней |
| `https://<домен>/build-pack/#/level/3` | сразу уровень 3, если он уже открыт у игрока; иначе экран уровней |
| `https://<домен>/build-pack/?unlock=all#/level/5` | любой уровень без прохождения предыдущих — для проверки, прогресс не трогает |

Маршруты в `#`, превью ссылки — `public/og.png`, иконка «На экран Домой» —
`manifest.webmanifest`; всё как у `apps/slide-out`.

## Витрина

Игра публикуется на общем сайте по адресу `https://<домен>/build-pack/` — это
`path` из `game.json`, там же название, жанр и питч для карточки. Отдельного
Vercel-проекта у игры нет: каждый пуш в `main` пересобирает сайт целиком
(`npm run build` в корне репо, см. `site/README.md`).

## Команды

```sh
npm install          # в корне репо, один раз на все игры (workspaces)
npm run dev          # http://<ip-компьютера>:5173 — открыть с телефона в той же Wi-Fi
npm test             # движок, солвер, уровни: решаемость, «змейка» не проходит 2–5 (§6)
npm run e2e          # пять уровней решением солвера, счётчик, препятствие, проигрыш, тач, «без прокрутки»
npx tsx tools/make-images.ts    # иконки и og.png из tools/brand.html
npx tsx tools/make-screens.ts   # экраны для UI Design/prototypes/build-pack (после npm run build)
npx tsx tools/build-artifact.ts # один HTML-файл для превью на claude.ai
```

## Устройство

- `src/engine/packEngine.ts` — правила §3–5 спеки и солвер: разложить поле на
  связные фигуры заданных размеров (каждая в 4×4), посчитать решения,
  проверить «змейку». В игре — только `hasMove`: проигрыш, когда ни одно
  оставшееся число никуда не помещается (`no_moves`). Решаемость наперёд игра
  не проверяет и не подсказывает — решение автора.
- `src/levels/levels.ts` — пять уровней: карта (`.` пусто, `#` препятствие,
  пробел — вне поля) и числа 4–7.
- `src/ui/game.ts` — игровой экран: поле сверху подстраивается под экран,
  внизу лоток — конструктор 4×4, числа, «Очистить», счётчик `k/N` в
  подсказке; перетаскивание фигуры на поле.
- Лог §8 пишется только на устройство: `localStorage['build-pack:log']` — на
  каждой укладке размер, форма, позиция, сколько раз очищали, время.
