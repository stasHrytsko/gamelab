# Burning Land — прототип

Спека — `specs/11-burning-land.md`, экраны — `UI Design/prototypes/burning-land/`.
Веб-игра под телефон: TypeScript + Vite, без фреймворка, экран на HTML/CSS,
перетаскивание на Pointer Events, стиль — токены и шрифт из `UI Design/`
(подключаются напрямую, не копией).

## Ссылки

| Ссылка | Что открывает |
|---|---|
| `https://<домен>/` | главный экран — эту ссылку и рассылать |
| `https://<домен>/#/levels` | экран уровней |
| `https://<домен>/#/level/3` | сразу уровень 3, если он уже открыт у игрока; иначе экран уровней |
| `https://<домен>/?unlock=all#/level/5` | любой уровень без прохождения предыдущих — для проверки, прогресс не трогает |

Маршруты в `#`, превью ссылки — `public/og.png`, иконка «На экран Домой» —
`manifest.webmanifest`; всё как у `apps/arrow-flip`.

## Vercel

1. Vercel → Add New → Project → импортировать репозиторий `gamelab`.
2. **Root Directory: `apps/burning-land`.** Остальное Vercel возьмёт из
   `vercel.json` (Vite, `npm run build`, `dist`).
3. Опция «Include files outside the Root Directory» должна остаться
   включённой: сборка читает `../../UI Design`, а тесты — `../../tools`.

## Команды

```sh
npm install
npm run dev          # http://<ip-компьютера>:5173 — открыть с телефона в той же Wi-Fi
npm test             # движок: постановка на траву, огонь/дом/стена/пепел/край запрещены, поворот
                      # без зеркала, 3 поворота на весь уровень (не на ход), шаг огня, победа «дома отрезаны»,
                      # спасённые клетки, house_burned, пропуск хода;
                      # уровни: копия солвера, линии солвера побеждают в движке, линии наивных
                      # стратегий дают тот же исход, kill-критерий (обе наивные проигрывают 3–5)
npm run e2e          # главный → победа на уровне 1 → уровень 2 открыт; все пять уровней линией
                      # солвера через настоящее перетаскивание; точки превью; тап-поворот и
                      # отпускание мимо не тратят ход; проигрыш и переигровка; «без прокрутки»
npx tsx tools/make-images.ts    # иконки и og.png из tools/brand.html
npx tsx tools/build-artifact.ts # один HTML-файл для превью на claude.ai
```

Солвер и генератор уровней — `tools/burning-land-solver.mjs` в корне
репозитория (`levels`, `kill`, `pick`, `pool`, `show`, см. §6 спеки).

## Устройство

- `src/engine/fireEngine.ts` — правила §4–5 спеки, порт `playTurn`/`spread`/
  `nextBurn`/`placementsOf` из солвера: `place` (стена → дома в безопасности →
  шаг огня → `house_burned` → дома в безопасности), `rotateSlot` (3 поворота
  на весь уровень, не на ход), `skipTurn` (правило 8), `anyFits`, `savedCount` — спасённая земля. Солвера в игре нет, проигрыш наперёд не считается.
- `src/levels/levels.ts` — пять уровней из `GAME_LEVELS` солвера вместе с
  очередью фигур: 1–2 обучающие, 3–5 с ловушкой. Очередь одна на уровень, после
  «заново» фигуры те же. `tests/levels.test.ts` сверяет копию с солвером.
- `src/ui/game.ts` — игровой экран и анимация §7.2: тап по фигуре — поворот,
  движение пальца больше 8 px — перетаскивание; призрак стоит на клетку выше
  пальца, синий или коралловый; точки превью пересчитываются под призраком.
  Стена защёлкивается за 120 мс, через 150 мс огонь шагает за 250 мс, фигуры
  «дальше» въезжают в трей. Победа — как только последний дом отрезан: огонь
  догорает волной в отданной части, волна по спасённой траве от домов, в
  попапе — сколько клеток спасено.
- Лог §8 пишется только на устройство: `localStorage['burning-land:log']` — на
  каждую постановку ход, фигура, поворот, клетки, сколько клеток на точках
  превью (`front_share`), поворотов и неудачных отпусканий в ходу, время хода;
  пропуски, победы (с числом спасённых клеток) и поражения.
