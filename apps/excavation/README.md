# Раскоп — прототип

Спека — `specs/24-excavation.md`, экраны — `UI Design/prototypes/excavation/`.
Веб-игра под телефон: TypeScript + Vite, без фреймворка, экран на HTML/CSS,
стиль — токены и шрифт из `UI Design/` в теме «Гробница» (`data-theme="tomb"`).

## Ссылки

| Ссылка | Что открывает |
|---|---|
| `https://<домен>/the-dig/` | главный экран — эту ссылку и рассылать |
| `https://<домен>/the-dig/#/levels` | экран уровней |
| `https://<домен>/the-dig/#/level/3` | сразу уровень 3, если он уже открыт у игрока; иначе экран уровней |
| `https://<домен>/the-dig/?unlock=all#/level/5` | любой уровень без прохождения предыдущих — для проверки |

Маршруты в `#`, превью ссылки — `public/og.png`, иконка «На экран Домой» —
`manifest.webmanifest`; всё как у `apps/sprout`.

## Витрина

Игра публикуется на общем сайте по адресу `https://<домен>/the-dig/` — это
`path` из `game.json`, там же название, жанр и питч для карточки. Отдельного
Vercel-проекта у игры нет: каждый пуш в `main` пересобирает сайт целиком
(`npm run build` в корне репо, см. `site/README.md`).

## Команды

```sh
npm install          # в корне репо, один раз на все игры (workspaces)
npm run dev          # http://<ip-компьютера>:5173 — открыть с телефона в той же Wi-Fi
npm test             # движок: число = ловушки = золото, выход, «Забрать» (нет выхода / нет 1★),
                      # ловушка сжигает золото, расчистка — победа; уровни: копия солвера, валидность
                      # раскладок, логика солвера в движке, случайный < 25%, баланс «до 2★» ≈ «до 3★»
npm run e2e          # главный → победа на уровне 1 → уровень 2; все пять уровней без риска; блок
                      # «Забрать»; ловушка и переигровка на следующей раскладке; подсветка соседей;
                      # «без прокрутки» на 360×560…430×932
npx tsx tools/make-images.ts    # иконки и og.png из tools/brand.html
npx tsx tools/build-artifact.ts # один HTML-файл для превью на claude.ai
```

Солвер, генератор и боты — `tools/excavation-solver.mjs` в корне репозитория
(`report`, `stops`, `json`, `log`, см. §6 и §8 спеки). `src/levels/levels.json`
— вывод `json`, `tests/levels.test.ts` сверяет копию с солвером.

## Устройство

- `src/engine/digEngine.ts` — правила §4–5: `tap` открывает плиту (ловушка →
  `trap`, иначе золото = число, выход → `exitFound`, последняя безопасная →
  победа), `take` — «Забрать» только с выходом и первой звездой.
- `src/engine/probability.ts` — порт `trapProbabilities` солвера для
  удержания: держишь число — соседи заливаются коралловым с насыщенностью по
  вероятности ловушки (§4, решение автора 2026-09-27). Тест сверяет порт с
  солвером. Остального солвера в игре нет.
- Попытка на уровне берёт раскладку `attempts mod 20` (`ui/storage.ts`), у
  всех игроков одна и та же последовательность; «Переиграть» — следующая.
- `src/ui/game.ts` — экран и анимация §7: переворот 150 мс, «+N» в счётчик
  400 мс, выход светится 600 мс; победа — звёзды, волна раскрытия комнаты,
  попап через 900 мс; ловушка — золото сгорает за 600 мс, раскрытие, попап.
  Попап не размывает поле: раскрытая комната — payoff.
- Главный экран: арта автора пока нет — название, честная мини-комната и
  кнопка «Играть».
- Лог §8 пишется только на устройство: `localStorage['excavation:log']` —
  старт попытки с раскладкой, каждый тап (клетка, исход, золото, время),
  «Забрать», блок «Забрать», победа, ловушка, брошенная попытка. Стопы,
  take_share и careless_taps считает солвер:
  `node tools/excavation-solver.mjs log <выгруженный лог.json>`.
