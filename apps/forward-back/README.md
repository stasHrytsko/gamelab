# Forward / Back — быстрый прототип для теста

Идея из ресёрча по Fanorona (механика «вперёд / назад»). **Это быстрая версия
для проверки гипотезы: спеки `specs/NN-…` и Gate 1 у неё нет.** Правила ниже
и в коде — рабочие, их нужно подтвердить на игре, после чего оформить спеку.

## Правила

- Поле 5×5, один герой и неподвижные враги.
- Ход = шаг героя на соседнюю свободную клетку (вверх/вниз/влево/вправо). Шаг стоит один ход.
- **Толчок** (в коде `forward`): шагнул к врагам — убираешь цепочку прямо перед клеткой, куда пришёл.
- **Рывок** (в коде `back`): шагнул от врагов — цепь утягивает цепочку прямо за клеткой, которую покинул.
- Если доступны оба варианта — нужно выбрать один (нельзя просто шагнуть). Если брать нечего — обычный шаг.
- Победа: врагов нет. Поражение: кончились ходы (`moves_exhausted`) или у героя нет
  свободных соседних клеток (`no_moves`).

## Управление (решение автора 2026-10-02: сделать причину и следствие видимыми)

- **Тап по врагу** = «убери его»: шаг и вид взятия выбираются сами. Каждого врага убирает
  не больше одного хода (лучи «вперёд» начинаются через клетку от героя, «назад» — вплотную),
  поэтому тап однозначен — это проверяет тест.
- **Прижал палец — видишь ход заранее**: призрак героя на новой клетке, обречённые враги
  дрожат в цветном кольце, при рывке видна цепь. Отпустил — ход. Увёл палец — отмена.
- Тап по пустой клетке — обычный шаг. Если с неё возможны оба взятия, ход не делается,
  подсказка просит тапнуть врага.
- **Отмена хода** без ограничений, в том числе из попапа поражения.
- Анимация объясняет правило: толчок отбрасывает линию вперёд, рывок тянет её за героем на тросе.
- Обучение по одному правилу: уровень 1 — только толчок (рука-подсказка), 2 — только рывок,
  3 — впервые оба на одном шаге; 4–5 — ловушки.

## Проверка гипотезы

Вопрос к игроку: **бывает ли выгоднее взять меньше?** Уровни 3–5 решаются
только с хотя бы одним ходом, где выбрана меньшая линия. Лог `localStorage['forward-back:log']`
пишет на каждом ходе `choice` (были ли обе линии) и `tookLess` (выбрана меньшая).

## Ссылки и команды

Витрина: `https://<домен>/forward-back/`; все уровни открыты сразу; `?lock=1` включает последовательное открытие.

```sh
npm install                      # в корне репо
npm run dev                      # в папке игры
npm run check                    # typecheck + vitest + build + playwright
npx tsx tools/gen-levels.ts 11 trap 2 6   # подбор уровней-ловушек (seed, режим, мин. выборов, мин. врагов)
npx tsx tools/make-images.ts     # иконки и og.png из tools/brand.html
npx tsx tools/build-artifact.ts  # один HTML для превью на claude.ai
```

## Устройство

- `src/engine/forwardEngine.ts` — правила: `stepInfo` (что даст шаг), `modesOf`
  (какие режимы допустимы), `move` (ход + статус).
- `src/engine/solver.ts` — BFS и «жадный» режим (всегда максимальное взятие); только для тестов и подбора уровней, в игру не попадает.
- `tools/gen-levels.ts` — подбор уровней солвером; в `levels.ts` числа не правим руками.
- `src/ui/game.ts` — экран: метки на клетках (шеврон — толчок, крюк — рывок), предпросмотр по
  удержанию, анимация толчка и рывка с цепью, отмена хода. Тайминги подобраны на глаз.
- Не сделано сознательно: цепочки как в настоящей Фанороне, диагонали, ящики-нейтралы, несколько героев.
