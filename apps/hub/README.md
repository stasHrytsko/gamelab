# hub — Prototype Validation Project

Один сайт-каталог: заголовок, короткое описание, «Prototype log» — сверху
всегда крупная плашка последнего прототипа, ниже пять пустых слотов-заглушек
под следующие. Мокап — `UI Design/prototypes/hub/`, здесь его рабочая
реализация. Каждый прототип (`apps/<slug>`) — свой отдельный Vercel-проект
со своей ссылкой; этот сайт только линкует на них, ничего не собирает внутрь
себя.

## Добавить прототип

Дописать объект в `src/games.ts`, в начало массива `GAMES` (самый новый —
первым, он и попадает в большую плашку с бейджем «Новое»):

```ts
{
  slug: 'slug-игры',
  title: 'Название',
  pitch: 'pitch_ru из specs/NN-slug.md, одной фразой',
  added: '1 окт.',
  levels: 5,
  family: 'головоломка',   // family из спеки, по-русски одним словом
  url: 'https://<домен>.vercel.app',
  cover: ['blue', 'red', 'yellow'],
}
```

Пока `url` пустой, карточка честно показывает кнопку «Скоро» вместо
нерабочей ссылки — заполнить, как только у прототипа появится боевой домен.

## Команды

```sh
npm install
npm run dev       # http://<ip-компьютера>:5173
npm run build      # tsc --noEmit + vite build → dist/
```

## Vercel

New Project → этот репозиторий → **Root Directory: `apps/hub`** — остальное
берётся из `vercel.json`.
