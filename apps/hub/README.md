# hub — Prototype Validation Project

Каталог всех прототипов: заголовок, короткое описание, «Prototype log» —
последний прототип как крупный герой-баннер во всю ширину (картинка, дата,
жанр, бейдж «New game», текст, кнопка), ниже «Coming up» — сетка карточек-
заглушек под ещё не собранные прототипы, с общей градиентной картинкой, а не
пустыми рамками. Десктопная веб-страница, не телефонный экран. Мокап —
`UI Design/prototypes/hub/`, здесь его рабочая реализация. Каждый прототип
(`apps/<slug>`) — свой отдельный Vercel-проект со своей ссылкой; этот сайт
только линкует на них, ничего не собирает внутрь себя.

## Добавить прототип

Дописать объект в `src/games.ts`, в начало массива `GAMES` (самый новый —
первым, он и попадает в герой-баннер с бейджем «New game»):

```ts
{
  slug: 'slug-игры',
  title: 'Английское название',
  date: 'Sep 25',
  genre: 'Puzzle',            // family из спеки, по-английски одним словом
  pitch: 'pitch_en из specs/NN-slug.md',
  banner: '/games/<slug>-banner.jpg',
  url: 'https://<домен>.vercel.app',
}
```

Картинку положить в `public/games/<slug>-banner.jpg` — широкая (у Taxi
Slide 1600×900), она растягивается на всю высоту баннера с тёмным градиентом
слева под текст. Пока `url` пустой, карточка честно показывает кнопку
«Soon» вместо нерабочей ссылки — заполнить, как только у прототипа появится
боевой домен.

## Команды

```sh
npm install
npm run dev       # http://<ip-компьютера>:5173
npm run build      # tsc --noEmit + vite build → dist/
```

## Vercel

New Project → этот репозиторий → **Root Directory: `apps/hub`** — остальное
берётся из `vercel.json`.
