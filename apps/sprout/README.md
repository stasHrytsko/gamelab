# Sprout — прототип

Спека — `specs/09-sprout.md`, экраны — `UI Design/prototypes/sprout/`. Веб-игра
под телефон: TypeScript + Vite, без фреймворка, экран на HTML/CSS, стиль —
токены и шрифт из `UI Design/` (подключаются напрямую, не копией).

## Ссылки

| Ссылка | Что открывает |
|---|---|
| `https://<домен>/` | главный экран — эту ссылку и рассылать |
| `https://<домен>/#/levels` | экран уровней |
| `https://<домен>/#/level/3` | сразу уровень 3, если он уже открыт у игрока; иначе экран уровней |
| `https://<домен>/?unlock=all#/level/5` | любой уровень без прохождения предыдущих — для проверки, прогресс не трогает |

Маршруты в `#`, превью ссылки — `public/og.png`, иконка «На экран Домой» —
`manifest.webmanifest`; всё как у `apps/arrow-flip`.

## Vercel

1. Vercel → Add New → Project → импортировать репозиторий `gamelab`.
2. **Root Directory: `apps/sprout`.** Остальное Vercel возьмёт из
   `vercel.json` (Vite, `npm run build`, `dist`).
3. Опция «Include files outside the Root Directory» должна остаться
   включённой: сборка читает `../../UI Design`, а тесты — `../../tools`.

## Команды

```sh
npm install
npm run dev          # http://<ip-компьютера>:5173 — открыть с телефона в той же Wi-Fi
npm test             # движок: шаг, вода −1/+X, камень/корень/даль, победа последним ходом,
                      # moves_exhausted и no_moves; уровни: копия солвера, пути солвера
                      # побеждают в движке, вся вода обязательна, kill-критерий (жадный проигрывает 3–5)
npm run e2e          # главный → победа на уровне 1 → уровень 2 открыт; все пять уровней путём
                      # солвера; вода и счётчик; недопустимые тапы; оба поражения и переигровка;
                      # «без прокрутки» на 360×560…430×932
npx tsx tools/make-images.ts    # иконки и og.png из tools/brand.html
npx tsx tools/build-artifact.ts # один HTML-файл для превью на claude.ai
```

Солвер и генератор уровней — `tools/sprout-solver.mjs` в корне репозитория
(`levels`, `kill`, `pick`, `log`, см. §6 и §8 спеки).

## Устройство

- `src/engine/sproutEngine.ts` — правила §4–5 спеки: `step` — порт `step` из
  солвера (рост на соседнюю клетку, −1, Б — победа, вода +X, запас 0 →
  `moves_exhausted`, тупик → `no_moves`); `reject` — почему тап не стал шагом
  (камень, корень, не сосед) для отклика на экране. Солвера в игре нет,
  решаемость наперёд не считается.
- `src/levels/levels.ts` — пять уровней из `GAME_LEVELS` солвера: 1–2
  обучающие (запас с люфтом), 3–5 с ловушкой (запас без люфта, ближайшая
  вода — приманка). `tests/levels.test.ts` сверяет копию с солвером.
- `src/ui/game.ts` — игровой экран и анимация §7.2: стебель вытягивается за
  180 мс, листок едет на новый кончик, капля сжимается в метку, «+X» летит к
  счётчику за 400 мс; победа — росток на Б и волна по корню.
- Лог §8 пишется только на устройство: `localStorage['sprout:log']` — на
  каждом шаге клетка, выпитая вода, запас, расстояние до ближайшей воды,
  номер попытки и время. `step_lost` считает солвер:
  `node tools/sprout-solver.mjs log <выгруженный лог.json>`.
