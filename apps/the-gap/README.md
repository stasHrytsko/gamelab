# The Gap — прототип

Спека — `specs/40-the-gap.md`, экраны — `UI Design/prototypes/the-gap/`.
Веб-игра под телефон: TypeScript + Vite, без фреймворка, экран на HTML/CSS, стиль —
токены и шрифт из `UI Design/` (подключаются напрямую, не копией).

## Ссылки

| Ссылка | Что открывает |
|---|---|
| `https://<домен>/the-gap/` | главный экран — эту ссылку и рассылать |
| `https://<домен>/the-gap/#/levels` | экран уровней |
| `https://<домен>/the-gap/#/level/3` | сразу уровень 3, если он уже открыт у игрока; иначе экран уровней |
| `https://<домен>/the-gap/?unlock=all#/level/5` | любой уровень без прохождения предыдущих — для проверки, прогресс не трогает |

## Витрина

Игра публикуется на общем сайте по адресу `https://<домен>/the-gap/` — это `path` из
`game.json`. Отдельного Vercel-проекта у игры нет: каждый пуш в `main`
пересобирает сайт целиком (`npm run build` в корне репо, см. `site/README.md`).

## Команды

```sh
npm install          # в корне репо, один раз на все игры (workspaces)
npm run dev          # http://<ip-компьютера>:5173 — открыть с телефона в той же Wi-Fi
npm test             # движок: скольжение, возврат, победа, лимит, звёзды; parity с солвером;
                      # уровни: решение через движок, без возвратов нерешаем (kill-критерий)
npm run e2e          # главный → победа на уровне 1 → уровень 2 открыт; все пять уровней
                      # сохранённым решением свайпами и тапами; недопустимое действие; поражение
                      # по лимиту и переигровка; «без прокрутки» на четырёх экранах
npx tsx tools/make-images.ts    # иконки и og.png из tools/brand.html
npx tsx tools/build-artifact.ts # один HTML-файл для превью на claude.ai
```

## Устройство

- `src/engine/gapEngine.ts` — правила §4–5 спеки: `planSwipe` и `planReturn` — порт `moves`
  из `tools/the-gap-solver.mjs`; `swipe` и `tapFlask` применяют ход к `GameState` и считают
  переход по §5 (победа → лимит ходов → нет ходов). Звёзды — `starsFor`.
- `src/levels/levels.json` — копия `tools/the-gap-levels.json` (пять уровней с сохранённым
  оптимальным решением, лимитом и порогами звёзд); тест сверяет копию с оригиналом.
- `src/ui/game.ts` — игровой экран: свайп по квадрату (порог 24 px, доминирующая ось, ход при
  отпускании, призрак назначения), счётчики целей, полоска запаса ходов, разбор образцом
  (`#/level/N/demo`), тап по колбе, анимация скольжения и въезда в колбу (`80 мс` на клетку, `220 мс` на въезд и
  выезд, WAAPI с `fill: 'forwards'`), недопустимое действие покачивает квадрат или колбу и
  вспыхивает клеткой выхода. Цвет квадрата дублируется значком (круг, треугольник, ромб).
- Арт главного экрана — арт автора (`UI Design/prototypes/the-gap/assets/home-art.webp`,
  оригинал `home-screen.png`); кнопка «Играть» настоящая, поверх обрезанного арта.
- Лог §8 пишется только на устройство: `localStorage['the-gap:log']` — на каждый ход тип
  (`swipe`/`return`), совпал ли ход с сохранённым решением, число возвратов и время с
  предыдущего хода.
