# hub — Prototype Validation Project

Каталог всех прототипов: заголовок, короткое описание, ниже — сетка карточек
по числу игр (сейчас 5): иконка, название, жанр, короткий питч и «Play →»,
открывает игру в новой вкладке. Десктопная веб-страница, не телефонный
экран, но сетка складывается в один столбец на телефоне без доработок.
Мокап — `UI Design/prototypes/hub/` (описывает более раннюю версию с героем
и заглушками, сейчас неактуален — обновить при следующей правке вида).

**Игры играбельны прямо с этого сайта, без отдельных Vercel-проектов
(решение автора 2026-09-28).** Раньше каждый прототип (`apps/<slug>`)
предполагался как свой отдельный Vercel-проект со своей ссылкой, а хаб
только линковал наружу — так и остаётся верно для будущих отдельных
деплоев. Но заводить пять доменов ради «зайти на сайт и сыграть» избыточно:
`public/games/<slug>.html` — это копия однофайлового артефакта каждой игры
(`npx tsx tools/build-artifact.ts` в её собственной папке — тот же скрипт,
которым публикуют игру в артефакт claude.ai). Файл самодостаточный: шрифты,
стили и картинки инлайном, роутер в памяти — открывается с любого пути без
доработок. Пересобрать после правок игры:

```sh
cd apps/<slug> && npx tsx tools/build-artifact.ts
cp apps/<slug>/dist-artifact/<slug>.html site/public/games/<slug>.html
```

Иконка — та же, что у самого прототипа: `cp apps/<slug>/public/icon-512.png
site/public/games/<slug>-icon.png`.

## Добавить прототип

Дописать объект в `src/games.ts` (порядок — по номеру идеи, самой хронологии
здесь больше не отражается):

```ts
{
  slug: 'slug-игры',
  title: 'Английское название',
  genre: 'Puzzle',            // family из спеки, по-английски одним словом
  pitch: 'pitch_en из specs/NN-slug.md',
  icon: '/games/<slug>-icon.png',
  play: '/games/<slug>.html',
}
```

Собрать артефакт и иконку по инструкции выше, ничего не собирается заново
при сборке хаба — файлы просто лежат в `public/games/` и коммитятся как
обычные статические файлы.

## Команды

```sh
npm install
npm run dev       # http://<ip-компьютера>:5173
npm run build      # tsc --noEmit + vite build → dist/
```

## Vercel

New Project → этот репозиторий → **Root Directory: `site`** — остальное
берётся из `vercel.json`. Один деплой отдаёт и хаб, и все пять игр — Root
Directory отдельных `apps/<slug>` для этого не нужен.
