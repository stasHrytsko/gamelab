# hub — Prototype Validation Project

Каталог всех прототипов: заголовок, короткое описание, «Prototype log» —
последний прототип как герой на две части: слева тёмная панель с бейджем
«New game», названием, датой, жанром, текстом и кнопкой (когда есть боевая
ссылка), справа сама картинка игры, без затемнения. Ниже «Coming up» —
маленькие карточки-заглушки под ещё не собранные прототипы, с общей
градиентной картинкой, а не пустыми рамками и без кнопки. Десктопная
веб-страница, не телефонный экран. Мокап —
`UI Design/prototypes/hub/`, здесь его рабочая реализация. Каждый прототип
(`apps/<slug>`) — свой отдельный Vercel-проект со своей ссылкой; этот сайт
только линкует на них, ничего не собирает внутрь себя.

## Добавить прототип

Дописать объект в `src/games.ts`, в начало массива `GAMES` (самый новый —
первым, он и попадает в герой-баннер с бейджем «New game»):

```ts
{
  slug: 'slug-игры',
  title: 'Английское название',
  date: 'Sep 25',
  genre: 'Puzzle',            // family из спеки, по-английски одним словом
  pitch: 'pitch_en из specs/NN-slug.md',
  banner: '/games/<slug>-banner.jpg',
  url: 'https://<домен>.vercel.app',
}
```

Картинку положить в `public/games/<slug>-banner.jpg` — широкая (у Slide
Out 1600×900), занимает правые 2/3 героя как есть, без градиента и
затемнения. Пока `url` пустой, кнопки на карточке нет вообще — не показываем
нерабочую ссылку — добавится сама, как только у прототипа появится боевой
домен.

## Команды

```sh
npm install
npm run dev       # http://<ip-компьютера>:5173
npm run build      # tsc --noEmit + vite build → dist/
```

## Vercel

New Project → этот репозиторий → **Root Directory: `site`** — остальное
берётся из `vercel.json`.
